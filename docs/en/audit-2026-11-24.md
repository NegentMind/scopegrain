# Scopegrain full audit — 2026-11-24

> English translation of the canonical Spanish document
> (`../audit-2026-11-24.md`). The Spanish version prevails.

Parallel audit of 15 domains performed with read-only subagents
(internal `file:line` investigation + industry comparison).
Reference state: `develop` branch, `scopegrain@0.1.1`, HEAD `889a61f`.

## Global verdict

Scopegrain is architecturally above the industry average in its domain
(transactional state, CAS, hash chains, documentary honesty, local API
security posture). Its product class is *workflow harness and
registry*, not a sandbox or enforcement mechanism: its gates are
verifiable-record discipline from the inside, not a security boundary
against an adversarial agent. Almost everything it does not guarantee
is declared in the docs.

## 1. "Global cross-agent system" viability

Viable as a layer composite; there is no — and should be no — "magic
binary".

| Layer | State | Missing |
|---|---|---|
| Global binary | global-safe (`import.meta.url`, 0 `process.cwd`, `--project PATH`) | `prepublishOnly`, `package-lock`, `catalog legacy` broken in package (`provenance/` excluded), owner authorization |
| Bootstrap | `AGENTS.md`/`CLAUDE.md` managed-section (convention read by 16-19 agents) | nothing |
| Bridges | superior declarative model; emits `SKILL.md` per the Agent Skills spec | Copilot (~62% enterprise) and Cursor (~22-43%) adapters — low cost |
| MCP | 35 hardened tools (2026-11-24 inventory) | `server.json`+`mcpName` for registry; per-host-format registration |
| State | project-local by deliberate invariant (`writeHostRoots:false`) | design decision — document, do not "fix" |

## 2. Confirmed code defects

### P0 — structural

1. `journal recover` on an archived op creates a shadow
   `operations/<id>/` → wedges `show`/`list`/`compact`
   (`journal.mjs:1368` hardcoded live path vs `operationBase`).
2. `host gate`/`task gate` exit 1/3 does not block under real Claude
   Code semantics (only 2 blocks) — latent fail-open with empty
   `hooks.json` (`gate-proposal.mjs:30-50`).
3. `policy/workflow.json`: `transitions`/`actions`/`acceptance` not
   pinned — `REVIEW→CLOSE` would bypass the universal gate without
   error (`policy.mjs:29-49`).
4. `assess` false negatives: `session|oauth|jwt|login|rbac|middleware|.env|
   Makefile|.github/actions|eval(` → `medium`/`review_due:false`
   (`risk-assess.mjs:15-31`).
5. `--lazy`/`--arguments`/`--script` rejected in aliases despite docs
   (`cli.mjs:688-691` `WORKFLOW_ALIAS_FLAGS`).

### P1 — functional

6. `verify run` broken on Windows for `.cmd` (npm/yarn/pnpm → EINVAL,
   no note).
7. `readHead` ignores `snapshots/`+`archive/` → a lost head restarts
   `journalSequence`=1 mixing live/archive (`journal.mjs:246-250`).
8. `researchEscalation` bypass: `VERIFY→EVALUATE→ACT`/`COLLATERAL→ACT`
   does not count rework (`methodology.mjs:225-227`).
9. Structure index >1 MiB is written but `readStructureIndex` rejects
   it (`structure.mjs:413 vs 456`).
10. IPv6 `--host ::1` broken: bracketed `[::1]` absent from
    `TRUSTED_HOSTNAMES` (`api/server.mjs:231`).
11. `decodeUtf8Strict` wrong signature in 6 call-sites → 500 instead of
    422 (`api/queries.mjs`).
12. `--apply` asymmetry: `dist bundle-uninstall`/`extension-remove`/
    `preset-remove`/`helper install`/`report save`/`task activate`/
    `task doc` mutate without preview.
13. `capture review` decisions not persisted → rejected proposals
    reappear (`capture-proposals.mjs`).
14. `host parity` blind to Codex TOML agents (`parity.mjs` +
    `native.mjs`).
15. `concurrency` in assess is an inert signal (`risk-assess.mjs:216-250`).
16. Non-ASCII paths quoted by git silently discarded in assess
    (`risk-assess.mjs:66`).
17. `memory_recall` explicit scope → machine-global pool
    (`mcp/server.mjs:455-459`).
18. `mcp_inventory` overdeclares `network:'never'`/`retryable:true`
    (`mcp-inventory.mjs:32-35`).
19. `Number()` unvalidated → `NaN` in journal/dist/vantadb flags
    (`cli.mjs`).
20. `update --reconcile` unlink without re-hash (vs `applyUninstall`
    which does re-hash) (`lifecycle.mjs:726-766`).

## 3. Structural gaps (declared design, to be decided)

- Unsigned records → tail truncation/rollback/whole-fabrication
  undetectable (honestly documented). Proposal: Ed25519/minisign signed
  checkpoint + `journalSequence` vs head check.
- Evidence attested, never executed: bind `verification.checks` to
  `verify run` records.
- Unauthenticated identity (`authorContext`/`reviewerContext`
  free-form).
- No upward `--project` autodetection.
- MCP without `outputSchema`/`structuredContent`/`title`.
- `session resume` restores operational state, not the conversation
  (naming).
- TOCTOU mkdir post-symlink-check (documented).
- 0-byte locks → 1h TTL; directory fsync missing (POSIX).
- No API↔viewer contract test, no i18n parity test.
- State coverage without a view: checklists/constitution/active-task.
- `catalog legacy` inoperable in the published install.
- `claude`-only config does not emit `AGENTS.md`; `generic` MCP without
  a merge target.
- `helper install` mutates without a gate; `report save`/`task doc`
  likewise.
- `memory_status` exposes absolute paths; `goal_transition` without CAS.
- `task gate` covers only the edit class, not Bash.
- init wizard prompts to stdout (TTY-gated).
- `--flag=value`, `--`, short flags and per-command help absent.
- No public error-code vocabulary; `INVALID_ARGS`→1.
- Implicit else-terminal to `cmdSession` (`cli.mjs:2961`).

## 5. Findings by domain (summary)

- **Journal**: correct and superior to git/npm (fsync, `{dev,ino,token}`
  locks, verify-per-read). Archived-op bug (P0-1) + missing dir fsync +
  head-loss.
- **FSM/methodologies**: real CAS, methodology+constraints pinned,
  approvals digest-bound. Incomplete pinning (P0-3), escalation bypass,
  attested evidence, unauthenticated identity.
- **Owned records**: chain correct as internal provenance; NOT
  tamper-evident vs rollback/whole fabrication (declared). Elegant
  prefix re-proof. No signatures.
- **MCP**: exact annotations 23+6+4+2; strict schemas; exemplary
  VantaDB spawn. Gaps: outputSchema, doc drift, inventory metadata.
- **API+viewer**: exemplary security (anti-DNS-rebinding, CORP, CSP);
  30/30 routes consumed. IPv6/decodeUtf8 bugs; no API↔viewer contract.
- **Hosts**: superior declarative model; inverted coverage
  (Copilot/Cursor missing); latent fail-open gate; TOML-blind parity.
- **Discovery**: "semantic" = root-only probes; assess fail-closed but
  narrow signals; internal graph JS/TS only; index >1MiB unreadable.
- **Memory/VantaDB**: "optional never authoritative" verified; secret
  egress fail-closed ×3; captures without review memory.
- **Security**: 0 critical/0 high in the threat model; supply chain
  without lockfile; verify run broken on Windows; unpinned PATH;
  LLM01 unmarked.
- **CLI**: 141 verbs (doc says 138; 2026-11-24 inventory); systemic --apply asymmetry in
  `dist`; NaN in numeric flags; no per-command help.
- **Docs**: 23/23 pair parity; severe staleness in system-report;
  docs-cli-drift blind to flags/counts/parity; no tutorial.
- **Testing**: solid in-process suite; no real binary, MCP stdio,
  kill -9, multi-proc locks, PBT, golden outputs, LLM evals.
- **npm**: global-safe; blockers prepublishOnly/lockfile/catalog
  legacy/authorization/name.
- **Global**: viable as a composite; binary ready; the projection model
  is the converging industry standard.

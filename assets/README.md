# Scopegrain brand assets

Original vector artwork for the Scopegrain mark and banner, matching the
approved visual direction in `.tasksystem/research/scopegrain-visual-brief.md`
and the private comps under `.tasksystem/research/design-preview/`.

## Files

| File | Size | Use |
| --- | --- | --- |
| `logo.svg` | 512×512 viewBox | Square mark: app icons, avatars, README headers. Transparent background. |
| `banner.svg` | 1600×560 viewBox | Wide banner: repository social/header, docs hero. Carries its own background. |
| `favicon.svg` | 512×512 viewBox | Simplified mark for 16–48 px favicons/touch icons. Ships its own chip background. |

## Motif

Two open frame corners (upper-left / lower-right) suggest *scope* — an open
frame, not a closed box. A diagonal staircase of squares runs from one large
square (scope) through mediums to a 2×2 cluster of small squares (grain),
expressing "from scope to granularity". The top-left small square carries the
clay accent; everything else is ink. The faint register grid appears only
behind the mark in the banner, per the brief.

## Dark / light behaviour

Each file is a **single asset** that adapts via an embedded
`prefers-color-scheme` media query (honoured by modern browsers when the SVG
is used as `<img>`, favicon, or inline):

- `logo.svg`: ink parts use `currentColor`; defaults to ink on light and
  flips to paper on dark. When inlined in HTML, the mark also follows the
  document's `color`.
- `banner.svg`: paper/ink/rule/grid/muted classes invert in dark scheme;
  the clay accent stays fixed.
- `favicon.svg`: paper chip + ink mark in light; ink chip + paper mark in
  dark — legible on any browser chrome.

## Typography

All text in `banner.svg` is converted to **glyph outlines** — no font is
loaded at runtime and no `<text>` element depends on installed fonts.
Sources (local files, SIL OFL — see
`.tasksystem/research/design-preview/font-sources.md`):

- Wordmark "Scopegrain": Bricolage Grotesque Bold, 91 px
- Descriptor "Proportional engineering for coding agents.": Instrument Sans
  Regular, 26 px
- Secondary line "Context / Decisions / Evidence": DM Mono Regular, 17 px

Fallback stacks for any future live text (from the brief):
headlines — Bricolage Grotesque, Outfit, Instrument Sans, Manrope, Noto Sans;
body — Instrument Sans, Public Sans, Manrope, Noto Sans;
mono — DM Mono, IBM Plex Mono, JetBrains Mono, Noto Sans Mono.
